# 从站底板（传感器 + RS485）PCB 设计规格 —— B 档

> 状态：**设计规格（未画板）**
> 日期：2026-10-19 15:0x
> 出具：审查官（esp 侧）｜实施方：用户（立创EDA / KiCad）
> 定位：**只画"底板/载板"，不画 MCU 主板** —— STM32F407 核心板与各传感器模块**以排针母座插接**
> ⚠️ 本规格**不含**已验证的核心板排针坐标（见 §2 待实测），画板前必须先量实物

## 0. 目标与边界

| # | 目标 | ⛔ 不做 |
|---|---|---|
| **GT-1** | 一块 2 层底板，承载 **STM32F407 核心板 + INMP441 + SHT30 + MAX3485 + OLED + 电源输入** | ⛔ 不把 MCU 芯片直接画在板上（无 BGA/无射频/无阻抗控制） |
| **GT-2** | 全部信号经**排针母座**连接，模块可插拔替换 | ⛔ 不做 EMC 认证级设计 |
| **GT-3** | RS485 侧做正确的端接与保护 | ⛔ 不做隔离 RS485（成本/体积不值） |

**为什么这个档位是最优解**：把"会不会画板"从门槛变成"会不会抄网络表"。难度集中在 **① 排针封装与核心板对齐 ② RS485 差分走线** 两点，其余全是直连。

## 1. 板级参数

| 项 | 值 | 说明 |
|---|---|---|
| 层数 | **2 层**（顶层信号 + 底层地平面为主） | 双层足够；底层尽量整片 GND |
| 板厚 | 1.6 mm | 常规 |
| 铜厚 | 1 oz | 常规 |
| 最小线宽/间距 | **0.25 mm / 0.25 mm** | 嘉立创免费工艺上限内（更细要加钱） |
| 最小过孔 | 0.3 mm 钻孔 / 0.6 mm 外径 | 常规 |
| 表面处理 | 无铅喷锡（HASL） | 便宜、好焊 |
| 尺寸 | **建议 ≤ 100 × 80 mm**（在 100×100 内单价最低） | 具体按核心板尺寸定 |
| 安装孔 | 4 × M3（φ3.2 mm） | 四角，距边 ≥3 mm |
| 丝印 | 每个连接器标**功能名 + 电压**；RS485 端子标 `A`/`B`/`GND` | ⚠️ 本项目有"丝印读反"前科（`T20`/`T21`） |

**打样**：嘉立创 5 片 ≈ ¥30~50（含阻焊/丝印），交期 3~5 天。

## 2. ⚠️ 待实测项（画板前必须先量，⛔ 不可猜）

| # | 待测 | 怎么测 | 为什么不能猜 |
|---|---|---|---|
| **M1** | **STM32F407 核心板排针**：排数（单/双）、间距（2.54 mm？）、**每针到板边距离**、两排间距 | 卡尺 + 万用表通断 | 全球 F407 核心板没有统一标准，**猜错 = 板子报废** |
| **M2** | 核心板**引脚丝印**（哪个针是 PA4/PB6/PD8…） | 对照核心板背面丝印 + 卖家资料 | 本项目已有"丝印语义读反"前科 |
| **M3** | INMP441 模块尺寸与排针间距（常见 2.54 mm 单排 6 针） | 卡尺 | 不同卖家排布不同 |
| **M4** | MAX3485 模块排针数（常见 2.54 mm 单排 6~7 针：`VCC/A/B/GND/DI/RO/DE~RE`） | 看模块丝印 | ⚠️ **本项目 RS485 模块两列不对称**，见 `硬件配置-2026-09-22.md` |
| **M5** | OLED 模块排针（常见 4 针 I2C：`VCC/GND/SCL/SDA`） | 看模块 | — |

## 3. 网络连接表（Netlist）

> 信号名以 `pin_config.h` 为准（`Inc/pin_config.h`）。⚠️ 从站寄存器语义见 `docs/spec/SoundDog-传感器扩展规格-SHT30-2026-10-19.md`。

### 3.1 电源

| 网络 | 来源 | 去向 | 备注 |
|---|---|---|---|
| `+3V3` | 核心板 `3.3V` 输出 | INMP441 VDD、SHT30 VCC、OLED VCC、MAX3485 **VCC**、I2C 上拉 | ⚠️ **RS485 模块 VCC = 3.3 V**（`硬件配置-2026-09-22.md:28,50`：**禁 5 V 进总线**） |
| `+5V` | 外部 DC 模块 5 V（端子） | 核心板 `5V` 输入（经板上 AMS1117 生成 3.3 V） | ⚠️ 与 USB 5 V 并存时由核心板二极管 OR，**本板不再加第二路** |
| `GND` | — | 全部 | **底层整片地，单点汇合到电源入口** |

### 3.2 I2S3 — INMP441（声学）

| 核心板脚 | 网络 | INMP441 |
|---|---|---|
| `PA4` | `I2S3_WS` | `WS`（LRCK） |
| `PB3` | `I2S3_CK` | `SCK`（BCLK） |
| `PB5` | `I2S3_SD` | `SD`（DOUT） |
| `+3V3` / `GND` | — | `VDD` / `GND` |
| `GND` | — | **`L/R` 接 GND**（选左声道；⚠️ 见 `S?` 坑：悬空会输出不定） |

### 3.3 I2C1 — OLED(0x3C) + SHT30(0x44)

| 核心板脚 | 网络 | 器件 |
|---|---|---|
| `PB6` | `I2C1_SCL` | OLED `SCL`、SHT30 `SCL` |
| `PB7` | `I2C1_SDA` | OLED `SDA`、SHT30 `SDA` |
| `+3V3` / `GND` | — | 两器件 VCC/GND |

**上拉电阻**：全总线**只留一组 4.7 kΩ**（`SCL`/`SDA` 各一，到底层 `+3V3`）。
⚠️ **画板前先确认 OLED/SHT30 模块是否自带 4.7 kΩ 上拉**（多数带）——若已带，**底板上不要再并**，否则总上拉降到 ~1.5 kΩ，部分器件拉不动。

### 3.4 USART3 — MAX3485（RS485）

| 核心板脚 | 网络 | MAX3485 |
|---|---|---|
| `PD8` | `RS485_TX` | `DI` |
| `PD9` | `RS485_RX` | `RO` |
| `PD12`（或实际 DE 脚，**待实测**） | `RS485_DE` | `DE` + `~RE` 短接 |
| `+3V3` | — | `VCC` |
| `A` / `B` / `GND` | 端子 | 差分对 + 地 |

**端接与保护**：
- **120 Ω** 跨接在 `A`—`B` 之间（**板载 1 只**；总线另一端由对端提供，全总线**共 2 只**）
- 建议加 **SM712**（或双向 TVS）在 `A`/`B` 对地，工业现场防浪涌
- 可选：`A` 上拉到 `+3V3`、`B` 下拉到 `GND` 各 **680 Ω**（失效安全偏置，仅**主节点**加）

### 3.5 其他

| 核心板脚 | 网络 | 器件 |
|---|---|---|
| `PB0` | `LED_ALARM` | 报警灯（限流 1 kΩ） |
| `PB1` | `LED_STATUS` | 状态灯（⚠️ 探针开着时该灯每帧应答翻转，语义见 `判据全集`） |
| `PE6` | `BUZZER` | 蜂鸣器（若为有源，加三极管驱动） |
| `PA9`/`PA10` | `USART1_TX/RX` | **调试串口排针**（引出 3 针：TX/RX/GND，方便接 USB-TTL） |
| `PA13`/`PA14` | `SWDIO`/`SWCLK` | **SWD 排针**（4 针：3V3/SWDIO/SWCLK/GND）——⚠️ 板上 GPIO 初始化**不得**把这两脚改 Analog |

## 4. 布局规则（按优先级）

| # | 规则 | 原因 |
|---|---|---|
| **L1** | **MAX3485 靠近 RS485 端子**，距离 <10 mm | 差分走线越短越好 |
| **L2** | **INMP441 远离** MAX3485 与电源入口、远离板边 | 麦克风怕噪声与振动耦合 |
| **L3** | **SHT30 远离** LDO/DC-DC 与 MCU（≥15 mm） | 否则测的是板子自己发热的温度 |
| **L4** | **OLED 与 SHT30 走线短**，同侧 | I2C 100 kHz，线长了加缓冲 |
| **L5** | 电源入口放 **10 µF + 0.1 µF**，每个 IC 电源脚再放 **0.1 µF** | 常规去耦 |
| **L6** | 底层**整片 GND**，少开槽；差分对下方**地完整** | 回流路径 |
| **L7** | 丝印标清每针功能 + 电压 + 极性 | 本项目丝印前科 |

---

## 5. 走线规则

| 信号 | 规则 |
|---|---|
| **RS485 `A`/`B`** | ⭐ **并行走线、等长（差 <5 mm）、间距恒定（≥3×线宽）**；不跨分割地；如需换层，`A`/`B` 一起换并在换层处加回流地过孔 |
| `+3V3` 主干 | **≥0.5 mm**（0.8 mm 更好）；从电源入口到各模块呈树状，不串糖葫芦 |
| `+5V` | **≥0.8 mm** |
| `GND` | 底层铺铜，顶层补地过孔 |
| I2S（`WS`/`CK`/`SD`） | ≥0.25 mm；`CK` 与 `SD` 尽量不平行长距离（防串扰），必要时中间夹地 |
| I2C | ≥0.25 mm；`SCL`/`SDA` 可并行，长度差无严格要求（100 kHz） |
| SWD | ≥0.2 mm，尽量短 |

## 7. 三个真实翻车点（本项目/通用血泪）

| # | 翻车点 | 后果 | 预防 |
|---|---|---|---|
| **F1** | 🔴 **核心板排针坐标猜错** | 整板报废（¥30 打样 + 一周交期） | **先量 M1/M2**；用"排针母座＋杜邦线"先验证一周，再定板 |
| **F2** | 🔴 **RS485 模块 VCC 接 5 V** | 本项目前科：**5 V 进总线 / 打穿 AMS1117** | 底板上 **`+3V3` 与 `+5V` 用不同宽度的走线并丝印标电压**；RS485 母座旁直接印 `3V3 ONLY` |
| **F3** | 🔴 **天线/晶振附近铺铜或长走线** | 若将来把 ESP32 也画进同一板：**天线下方禁铜禁走线** | 本档**不画 ESP32** ⇒ 风险为零；若后续要画，单独立规格 |
| **F4** | ⚠️ **SHT30 贴着 LDO** | 测的是自己板温，读数偏高 3~5 °C | 布局规则 **L3** |

## 8. 交付与验收

**交付物**：立创EDA/KiCad 工程（原理图 + PCB）＋ Gerber ＋ BOM ＋ 打样订单截图。

| # | AC | 判据 |
|---|---|---|
| **AC-1** | 电气连通 | 万用表通断：`+3V3` 对 `GND` **不短路**（>1 kΩ）；`+5V` 对 `GND` 同 |
| **AC-2** | 上电电压 | `+5V` ≈ 5.0 V；核心板 `3.3V` ≈ 3.3 V |
| **AC-3** | RS485 端接 | `A`—`B` 直流电阻 ≈ **120 Ω**（断电测） |
| **AC-4** | I2C 总线 | 上电扫址能看到 **`0x3C` + `0x44`** 两个设备 |
| **AC-5** | 差分波形 | 示波器看 `A−B` 有明确跳变（⚠️ 本项目 **`A/B` 反相前科**：`判据全集 §6bc`） |
| **AC-6** | 声学链路 | `COM4` 出现 `SPEC/MFCC/MEL` 流水线输出（与面包板期一致） |

## 10. 待实测 / 边界

1. ⚠️ **§2 的 M1~M5 全部未测** —— 本规格**不能直接开画**，必须先量。
2. ⚠️ **MAX3485 的 DE 脚实际接哪个 GPIO 未核**（`pin_config.h` 未定义 `RS485_DE`）⇒ 画板前须查 `gpio.c`/`portserial.c`。
3. ⚠️ 本档**不含 ESP32 网关板**；若将来要一体化，需另立规格（含天线净空、射频）。
4. ⚠️ 打样前建议先跑 **DRC + 3D 预览**，重点看排针母座与核心板是否**机械干涉**。
5. ⚠️ 毕设要求**未强制** PCB ⇒ **PCB 是加分项**；先用洞洞板跑通系统，避免为了画板拖住联调。
