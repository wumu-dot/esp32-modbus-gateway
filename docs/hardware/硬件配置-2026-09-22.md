# ESP32-Modbus-Gateway 硬件配置（ESP32-S3-N16R8 板 / MAX3485 / 接线）

> 目的：固化网关板实际引出引脚、与 MAX3485 接线、A/B 总线互连，供联调/排查复用。
> 权威来源：2026-09-22 实物排针确认；Kconfig 引脚默认值。
> 本文档是网关侧单一权威硬件台账（对齐 SoundDog 硬件配置-2026-09-16.md 惯例）。

## 1. 板型与排针引出（2026-09-22 实物确认）

板型：ESP32-S3-N16R8（16MB Flash + 8MB Octal PSRAM），双排针。

### 左侧排针（从上往下）
1. 3V3 / 2. 3V3 / 3. RST / 4. GPIO4 / 5. GPIO5 / 6. GPIO6 / 7. GPIO7 / 8. GPIO15 /
**9. GPIO16**（← MAX3485 TX/RO）/ **10. GPIO17**（→ MAX3485 RX/DI）/ 11. GPIO18 / 12. GPIO8 / 13. GPIO3 / 14. GPIO46(RGB) / 15. GPIO9 /
**16. GPIO10**（→ MAX3485 EN/DE/RE）/ 17. GPIO11 / 18. GPIO12 / 19. GPIO13 / 20. 14(不清) / 21. 5V / 22. GND

### 右侧排针（从上往下）
1. GND / 2. GPIO43(UART_TX) / 3. GPIO44(UART_RX) / 4. GPIO1 / 5. GPIO2 / 6. GPIO42 / 7. GPIO41 / 8. GPIO40 / 9. GPIO39 / 10. GPIO38 / 11. GPIO37 / 12. GPIO36 / 13. GPIO35 / 14. GPIO0(BOOT) / 15. GPIO45 / 16. GPIO48 / 17. GPIO47 / 18. GPIO21 / 19. GPIO20 / 20. 不清(可能5V) / 21. GND / 22. GND

> GPIO43/44 = 烧录/调试口（勿接 MAX3485）。**GPIO19 未引出**，DE/RE 用 GPIO10。

## 2. 网关侧接线（ESP32-S3 ↔ MAX3485）

| ESP32-S3 | 功能 | → MAX3485 丝印 | 芯片功能 |
|---|---|---|---|
| **GPIO17** | UART TX | **→ `RXD`** | = `DI`（模块**收**） |
| **GPIO16** | UART RX | **← `TXD`** | = `RO`（模块**发**） |
| **GPIO10** | GPIO RTS | **→ `EN`** | ≈ `DE`/`/RE` |
| 3V3 | 供电 | → `VCC` | 3.3V |
| GND | 共地 | → `GND` | |

> 🔴 **2026-09-28 丝印记法更正**：实物丝印为 **`RXD` / `TXD`（带 D 后缀）**，
> 本文件原写的 `RX` / `TX` **已作废**（实物 = 模块 `RS485` / `V2.0`，**两列不对称**布局：
> 左列 `EN / VCC / RXD / TXD / GND`、右列 `GND / A / B`）。
> ⚠️ **权威源**：`桌面\stm32F407ZGT6\MAX3485-RS485模块资料\README.md`（厂商商品详情页 + 原图）。
>
> **语义（必须交叉）**：模块 `TXD` = 芯片 `RO`（模块**发**）⇒ 接主控 **`UART_RX`(GPIO16)**；
> 模块 `RXD` = 芯片 `DI`（模块**收**）⇒ 接主控 **`UART_TX`(GPIO17)**。
> （`TXD` ← Transmit ⇒ 模块往出发 ⇒ 接主控收脚；`RXD` ← Receive ⇒ 接主控发脚。）
>
> ⚠️ **本条只改丝印记法与语义标注，`GPIO17/16/10` 的对应关系不变**（与 SoundDog R42 一致）。

## 3. A/B 差分总线互联

网关侧 A ── SoundDog 侧 A；网关侧 B ── SoundDog 侧 B。
从站侧权威接线见 SoundDog docs/hardware/硬件配置-2026-09-16.md §2/§3。

## 4. 通电前硬性判据（R36/R40）

1. 共地链四端导通 ≈0Ω（ESP32 GND → 网关 MAX3485 GND → SoundDog GND → 从站 MAX3485 GND）。
2. 两个 MAX3485 VCC 均接各自板载 3.3V，禁 5V 进总线。
3. 通电量电压 5V≈5V、3.3V≈3.3V。
4. 未全合格前禁止 A/B 总线自检。
