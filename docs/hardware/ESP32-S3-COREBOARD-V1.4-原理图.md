### 存疑项（图上存在、但语义需实物确认）

1. **J1 pin21 / `IN-OUT`** —— 🔴 **仍未定案（2026-10-20 两次反复，见下）**

   | 来源 | 说法 | 权威度 |

   | **本板原理图（本文件 `§4`）** | `J1.21 — D3 — 5V`；同节点另有一只 **0Ω（丝印 `IN-OUT`）接 GND** | ⭐⭐ 人看图转写，可能误读 |

## 5. 各功能块连接（图上读出的网络）

### 5.1 供电

```
USB1.VBUS ─(D1= D26)─┐
                      ├─→ 5V ─→ [J1.21] / U3.IN / U1.VDD / R6(LED-RED)
USB2.VBUS ─(D2= D26)─┘
U3 CJ6107A33GW : 5V → VDD33   (C3 10µF 输入, C4 10µF 输出)
VDD33 ←→ U4.3V3(2) / U2.VIO(1) / R8(EN 上拉) / R11(GPIO3 上拉)
```
- USB2 侧另有 **`USB-OTG` 0Ω(0,0603)** 串在 VBUS 支路上（图上为一个跳线位）。
- USB1 `VBUSB` → 同时送 **U2 pin3 `VDD5`** 与 **U2 pin9 `VBUS`**（C1 1µF 去耦）。
- `VDD33` 去耦：C5 10µF/0603 + C6 104/0402；`CHIP_PU` RC：R8 10k + C7 1µF。

### 5.2 USB-UART（USB1 → CH343P）

| U2(CH343P) | 连到 | 说明 |
|---|---|---|
| 1 VIO | `VDD33`（C10 1µF） | |
| 2 GND | GND | |
| 3 VDD5 | `VBUSB` | 仅插 USB1 时上电 |
| 4 TXD | **`U0RXD`**（GPIO44） | 交叉，正确 |
| 5 RXD | **`U0TXD`**（GPIO43） | 交叉，正确 |
| 6 V3 | C2 100nF → GND | 内部 LDO 输出 |
| 7 UD+ / 8 UD− | USB1 `D+` / `D−` | |
| 9 VBUS | `VBUSB` | |
| 12 DTR / 13 RTS | → R5/R7 10k → **Q1 / Q2** | 自动下载 |
| 10/11/14/15/16 | 未接（ACT#/DCD/DSR/CTS/RI） | |

**自动下载电路**（图上文字：`Auto program DTR RTS-->EN IO0`）：
`DTR —R5 10k— Q1(SS8050-G) —→ CHIP_PU（EN）`；`RTS —R7 10k— Q2(SS8050-G) —→ GPIO0（IO0）`。
即经典 ESP32 双管自动下载，与模组 EN/IO0 配合。

### 5.3 板载 RGB

`GPIO48 —0Ω(0,0603) `RGB_CTRL` —→ U1.XL-5050RGBC-WS2812B.DI`；U1.VDD ← `5V`；U1.GND → GND；U1.DO 空。
→ **RGB 实际驱动脚是 GPIO48**（不是 GPIO46）。

### 5.4 按键与 strap

| 项 | 连接 |
|---|---|
| BOOT | ST-1185S：`1→GND`、`2→GPIO0`；C8 104 并联（去抖） |
| RST | ST-1185S：`1→GND`、`2→CHIP_PU`；C9 104 并联 |
| GPIO0 | strap（启动模式）+ 按键 + Q2 |
| GPIO3 | strap（JTAG 信号源）：`VDD33—R11 10k—USB-JTAG 0Ω—GPIO3` → 选**内置 USB-JTAG** |
| GPIO45 | strap（VDD_SPI 电压），仅引到 J2 pin15，板上无上下拉 |
| GPIO46 | strap（ROM 打印），仅引到 J1 pin14 |
| GPIO19/20 | 原生 USB D−/D+，已接 USB2（OTG）口 |

（`ESP32-S3-WROOM-1`），**不含 Flash/PSRAM 容量标注**，因此：

- 原理图能背书的：模组为 **ESP32-S3-WROOM-1 标准 41 脚封装**、外设连接关系（本文件全部内容）。
- 原理图**不能**背书的：N16R8 的容量与 Octal PSRAM 配置 —— 这一项仍只由实物丝印 + `sdkconfig`
  （`CONFIG_SPIRAM=y` / `MODE_OCT` / `TYPE_AUTO` / `SPEED_80M`）支撑，与本文件无关。

   本工程只用它做打印口 —— 与本图一致，无需改动。
2. **GPIO19/20 不可挪用**：这两脚在板上直接接 **USB2（OTG）口**的 D−/D+，
   若在网关里把它们配成 GPIO，会与 USB2 口冲突。本工程未用，符合原理图预期。
3. **GPIO45 / GPIO46 带 strap 语义**（VDD_SPI 电压选择 / ROM 打印），现分别只引到 J2 pin15 与 J1 pin14；
   若日后要拿它们做输出（如继电器指示），需注意上电时刻的电平要求。**GPIO46 并非 RGB 脚**（RGB 走 GPIO48）。
4. **GPIO33~37 不可用**：本板 N16R8 的 Octal PSRAM 内部占用这五脚（论证见 §3 警示框）。
   其中 `GPIO35/36/37` 虽引到 **J2 pin13/12/11**，但**只能作"连通记录"，不可接外设**。

## 8. 与既有台账的差异清单

对比 `docs/hardware/硬件配置-2026-09-22.md`：

| 项 | 台账 | 原理图 | 处置 |
|---|---|---|---|
| J2 pin20 | 「不清（可能 5V）」 | `GPIO19` | **台账应更正为 GPIO19** |
| J2 pin1/pin19 | `GND` / `GPIO20` | `GND` / `GPIO20` | 一致 |
| J2 pin2–18（共 17 项） | 逐条 | 逐条 | **逐条一致** |
| J2 pin21/22 | GND / GND | `GND` / `GND`（同一网络） | 一致 |
| J1 全 22 针 | 逐条 | 逐条 | **逐条一致（含 1/2 = 3V3、3 = RST、21 = 5V、22 = GND）** |
| 板型 | ESP32-S3-N16R8 | 模组级 `ESP32-S3-WROOM-1` | 不冲突（原理图不含容量信息） |

> 该台账 2026-09-22 由实物排针确认，与原理图互为独立来源而结论一致（唯一例外是 J2 pin20）——
> 台账可信度因此上一个台阶。
